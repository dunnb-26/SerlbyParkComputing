Blue Task: Analyzing Blagging

Read the scenario and answer the questions below.
"A cyber criminal wants to gain access to a school's network. They call the school receptionist, claiming to be an IT engineer from the local council. They say there is a critical server fault and they urgently need a staff password to log in remotely and fix it."

Extension Task: Think Like an Attacker

Create a short blagging email that tries to convince the recipient that they need to send you some money. The reasoning is up to you, but make sure to include some obvious characteristics of blagging emails.
